Open-source TypeScript agent harness

Agents that live in real conversations, without the harness tax.

Most agent frameworks assume one developer, a local terminal, and a stack of config files. chaff is built for agents that behave like humans digitally: multi-party group threads, real-time voice calls, passage of time, and knowing when to stay quiet.

Dynamic skill loading, per-turn thinking routing, and three-tier compaction happen automatically, cutting output tokens by up to 89% on the exact same model with no knobs to tune.

The premise

A harness is not neutral plumbing. It shapes the tool schemas, formats the history, decides what stays in context, and determines whether your prompt cache hits 55% or 0%. You do not need to wait for the next frontier model to cut your token bill in half.

Architecture

Built for how people actually communicate

01

Multi-party first, not user/assistant ping-pong

Real messaging is not an alternating two-role array. chaff tracks named participant_utterance turns, message edits, emoji reactions, and out-of-band external_event webhooks separately from the model's own thoughts. When two humans are talking to each other in a group chat, the agent emits do_nothing and stays silent instead of chiming in on every message.

participant_utterance do_nothing external_event edits & reactions
02

Time is part of the state

Every turn carries timestamps and an IANA timezone. Long threads segment naturally on 30-minute conversation gaps, idle skills unlearn themselves once the topic moves on, and each turn respects a wall-clock execution budget alongside iteration caps.

timezoneIANA gap segmentation turn time budgets
03

One harness for IM and real-time voice

Pass the same AgentSpec, tools, skills, and event log to text channels (Gemini, Anthropic, Kimi with automatic safety-block fallback) or switch to transport: { kind: "audio" } for full-duplex Gemini Live calls with barge-in interruption handling.

Gemini / Claude / Kimi Gemini Live duplex barge-in flush
04

Economical and dynamic, with no knobs to babysit

Instead of asking you to hand-wire static tool subsets, reasoning budgets, and summary schedules, chaff adapts per turn. A lightweight decision model activates only the skills needed now and picks thinking depth (LOW, MEDIUM, HIGH). Large tool outputs spill to a scratchpad, settled sessions compact into structured summaries, and deterministic guards catch repetition floods, truncation, and unbacked claims at zero happy-path token cost.
