Group chat

Multi-party, not user/assistant

Real chats have multiple speakers, edits, reactions, and async webhooks. When two people are talking to each other, the agent emits do_nothing and stays quiet instead of replying to every line.

Time-aware

Every turn carries timestamps and an IANA timezone. Threads segment naturally on 30-minute gaps, idle skills unlearn themselves once the topic moves on, and turns obey wall-clock budgets.

IM and real-time voice on one loop

The same AgentSpec, tools, and event history drive Gemini, Claude, and Kimi over messaging, or full-duplex Gemini Live audio with barge-in handling.

Economical and dynamic, without knobs

On-demand skill loading, per-turn thinking-level routing, three-tier compaction with scratchpad spills, and deterministic happy-path guards run automatically. No manual tuning, no bloated startup prompt.

More under the hood skills, scratchpad, compaction, guards

Skills power on and off automatically

Inactive skills stay out of tool declarations so unused schemas do not inflate every turn. A lightweight decision router turns on only the skills relevant to the current turn, and idle skills auto-unlearn once the conversation moves on.

Tool output scratchpad

Large tool responses spill automatically into a scratchpad instead of clogging active context. The model receives a short preview plus a SCRATCH: handle it can paginate with read_scratch_file or pass straight into another tool's arguments.

Three-tier compaction and history search

Completed tool arguments and results fold in memory, while settled 30-minute sessions roll up into structured summaries (entities, decisions, actions, pending, abandoned) without ever splitting a tool_call from its tool_result. Older turns stay reachable via search_past_history and clean_active_memory.

Per-turn thinking-level routing

Before calling the main model, a fast decision router picks LOW, MEDIUM, or HIGH thinking depth, so quick replies and lookups do not pay for deep reasoning.

Zero-cost happy-path guards

Deterministic checks catch repetition loops, emoji floods, leaked internal thoughts, mangled tool calls, and truncated replies. Hallucination and unbacked-action audits only fire when triggered, adding zero tokens on normal turns.

Provider fallback and Gemini thought signatures

Preserves Gemini thoughtSignature pairing across turns to prevent thinking-model limit-cycle loops, falls back cleanly to Kimi on false-positive safety blocks, and recovers gracefully from oversized or corrupted media.

Deferred async tools and external events

Long-running tools can suspend a turn and resume on a later wakeup. Webhooks and background jobs enter history as external_event records kept distinct from the model's own thoughts.

Structured JSON and context injection

Includes Zod-typed genJson helpers and AsyncLocalStorage-backed dependency injection for API keys, history stores, caching, and streaming callbacks without threading config objects everywhere.

Terminal-Bench 4.1 spot-check

gemini-4-hydrogen · k=1

chaff is built for IM and voice, not coding CLIs. To stress-test long multi-step loops, prompt caching, scratchpad spills, and multimodal tool outputs on a held-constant model, we ran a 7-task k=1 spot-check on Terminal-Bench 4.1 via Harbor on Modal using a minimal 5-tool wrapper (bash, read_file, write_file, edit_file, finish) and compared five of them head-to-head against Google's antigravity-cli (the official TB 4.1 harness for gemini-4-hydrogen, 56.4% across all 66 tasks at k=5).

This is a spot-check, not a full 66-task k=5 leaderboard run (~$800 in inference). Running real 20–71-step trajectories caught two harness bugs that are now fixed and shipped: mid-turn tool-arg folding / wall-clock decay busting Gemini's prefix cache (v0.4.2, lifting bun-sourcemap-leak cache hit from 60.4% to 84.7%), and spilled scratchpad previews exceeding the 15k threshold by the notice length and self-compacting on turn +1 (v0.4.3).

Takeaway: With a bare 5-tool wrapper, chaff passed 4/7 tasks (including multimodal PDF/CAD runs), held 83–96% prompt cache hit rates with zero mid-turn cache busts up to 237k context, and matched or beat antigravity-cli on the five shared tasks.
